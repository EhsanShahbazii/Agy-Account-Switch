# سوییچر چنداکانته برنامه آنتی‌گرویتی (Antigravity)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-macOS-lightgrey.svg)](https://apple.com)

یک ابزار سبک، زیبا و کاملاً بومی (Native) برای تغییر سریع و آسان بین چندین اکانت Gemini Pro در برنامه دسکتاپ **Google Antigravity** برای مک (macOS).

> 🇬🇧 **English**: For the English documentation, see [README.md](README.md).

---

## ✨ قابلیت‌ها

- **تزریق مستقیم و بومی به اپلیکیشن**: دکمه تغییر اکانت درست در نوار ابزار ورودی متن در کنار منوی مدل قرار می‌گیرد.
- **طراحی کاملاً هماهنگ و یکپارچه**: رنگ‌ها، فونت‌ها، سایه نرم (`shadow-md`)، آیکون‌های رسمی متریال گوگل، و استایل دقیق منوی برنامه.
- **تراز دقیق تیک فعال به گوشه راست**: نمایش تیک اکانت فعال در منتهی‌الیه سمت راست (دقیقاً مشابه منوی اصلی مدل‌های اپلیکیشن).
- **امکان تغییر نام اکانت (Rename)**: تغییر نام آسان اکانت‌ها بدون نیاز به ویرایش فایل و با کلیدهای میانبر (Enter برای ذخیره، Esc برای انصراف).
- **صفحه بارگذاری زیبا و مات**: در زمان سوییچ اکانت، صفحه لودینگ اختصاصی با انیمیشن پالس نقطه‌ای و پس‌زمینه کاملاً مات نمایش داده می‌شود.
- **امنیت بالا با macOS Keychain**: توکن‌ها با امنیت کامل در Keychain مک و پوشه شخصی `~/.gemini/accounts/` نگهداری می‌شوند.
- **نصب و حذف خودکار با یک کلیک**: ایجاد بک‌آپ خودکار از فایل اصلی برنامه و امکان بازگردانی کامل به حالت اولیه در هر زمان.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. دریافت مخزن و نصب
```bash
git clone https://github.com/EhsanShahbazii/agy-account-switch.git
cd agy-account-switch
./scripts/install.sh
```

### ۲. اجرای مجدد برنامه
برنامه **Antigravity** را یک‌بار ببندید و مجدداً باز کنید. دکمه انتخاب اکانت در کنار منوی مدل ظاهر خواهد شد.

---

## 🛠️ بررسی وضعیت و خطایابی

برای بررسی سلامت نصب و فایل‌های برنامه:
```bash
./scripts/doctor.sh
```

استفاده از ترمینال برای تغییر اکانت:
```bash
node bin/agy-switch.js list
node bin/agy-switch.js switch <accountId>
```

---

## 🔄 حذف و بازگردانی به نسخه اصلی

اگر تمایل داشتید پچ را حذف کرده و برنامه را دقیقاً به حالت اولیه کارخانه بازگردانید:
```bash
./scripts/uninstall.sh
```
